An ISO code such as en, de, ja, or auto to detect it. English-only models (.en) ignore this.

Requires a multilingual model, not an .en one. Note that large-v3-turbo cannot translate either — it silently transcribes in the source language instead. Use Small or Medium.

Removes silence and music before transcription, which is where invented text comes from. Needs the voice activity model — fetch it from Plugins → Live CC Generator. Trade-off: it can also discard quiet speech, and the threshold does not behave predictably — on one test passage 0.5 and 0.2 returned nothing while 0.3 transcribed correctly. Leave off unless hallucinations bother you, and re-check the result after changing it.

Transcription pacing

Shorter chunks reach the screen sooner; longer chunks give the model more context and read better. "Chunks ahead" is how far past the playhead to stay buffered. Threads 0 lets whisper.cpp decide.
